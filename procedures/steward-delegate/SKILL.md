# Delegate

Use this procedure only when the host actually exposes collaboration tools and independent work can materially improve time or quality. Steward has no subagent runtime. Do not describe a brief or journal entry as a launched agent.

Provide an objective, absolute project path, revision or observed source identity, allowed files, constraints, acceptance criteria and evidence format. Never invent a revision for an unversioned directory. State whether the assignment is read-only or allows specified edits, and identify any separately authorized external effects. A task brief does not expand the parent's authority. Avoid concurrent ownership of the same files; isolate work when the host supports it. Do not delegate serial prerequisites or commission duplicate checks merely to use another agent.

Continue useful independent work in the parent session. Ask agents to return missing inputs or ownership conflicts rather than widen their scope. Inspect returned artifacts, resolve conflicts and reuse relevant check results; run integration checks only where the combined change needs them. A second agent's assertion is not verification evidence by itself.

Input: an available collaboration tool and independent work scopes. Result: bounded assignments and an integrated, checked result, or direct local execution when delegation is inappropriate.
