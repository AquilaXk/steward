`.nvmrc`. Historical 0.1.1 artifacts remain unchanged in this directory.

- Run `npm test`: 151 tests pass, with no failures, skips or cancellations.
- Add failing regressions before implementing bounded current-memory queries,
  immutable schedule revisions and managed installation lifecycle operations.

  update conflict leaves host configuration unchanged.
- Correct a Windows-only test assumption discovered in CI: compare the recorded
  CLI path with the actual platform-native toolkit path, rather than searching
  for a POSIX slash substring. The runtime path itself required no change.
- Validate the Claude plugin with Claude Code 2.1.226. Its warning identifies

  setup creates the actual import. The plugin ships its procedures as skills.

The local Plugin Creator helper rejects custom skill directory names. Steward
uses the current [official manifest path contract](https://developers.openai.com/plugins/build/plugins),
which resolves bundled component paths relative to the plugin root. The repository
check validates those exact paths and generated Claude artifacts. The helper's
directory convention is not claimed as a passing native loader test.

Native model execution and the nineteen supervised behavioral cases remain
unverified. Local hook subprocesses and package validators do not establish host
enforcement or comparative model quality. The current PR's required CI matrix
